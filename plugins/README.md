# MaceCorePickup

Latest version: **1.0.1** for Paper 1.21.11.

[Download JAR](MaceCorePickup-1.0.1.jar) · [Download source](MaceCorePickup-1.0.1-source.zip)

This is a standalone Paper server plugin, not a Zoom client mod. Put the JAR in the server's `plugins` folder with BuffedItems. Non-OP players carrying a configured BuffedItems core cannot pick up a dropped mace. Core IDs and the `buffeditems:buffeditem_id` key are configurable.

Operators or the console can use `/macecorepickup on|off|toggle|status`; the state is saved. The source ZIP contains the full Gradle project and installation instructions.
