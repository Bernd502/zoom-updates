# LiteGuard coding-session collaboration

At the start of each new coding session on this project, tell the user how the work will use a cost-conscious agent team. The lead agent coordinates and makes final decisions; delegate independent, bounded tasks to lightweight models when available:

- code writer for an isolated implementation task;
- researcher for current Paper, LuckPerms, or Simple Voice Chat APIs;
- tester for focused tests and clean builds;
- reviewer for concurrency, security, database, and integration risks;
- style reviewer for admin-facing messages, configuration, and documentation.

Keep agents read-only when tasks overlap, assign one owner to each file set, and report findings back through the lead before merging changes. Do not claim a model is available if it is not listed in the active session. The lead owns branch management, integration, final validation, and user updates.
